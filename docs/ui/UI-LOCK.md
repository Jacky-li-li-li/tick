# Tick 面板 UI 锁定（2026-10-16）

视觉稿：`docs/ui/Tick-UI-Board.png`（19 帧）· 帧内可交互 HTML：`docs/ui/board.html`

## 视觉 · 磨砂半透明玻璃

- 面板 **360×520**（与 `apps/desktop/src/main/index.ts` 的 BrowserWindow 一致），圆角 18，无边框、可拖动区为顶栏空白
- 玻璃：底色 `rgba(20,22,34,.50)` + 顶部高光渐变 `rgba(255,255,255,.10) → 0`；`backdrop-filter: blur(30px) saturate(180%)`；描边 `rgba(255,255,255,.16)`；内高光 `inset 0 1px 0 rgba(255,255,255,.22)`；投影 `0 30px 70px rgba(6,8,18,.55)`
- 弹层（`···` 菜单 / sheet / 托盘菜单）：`rgba(24,26,40,.84)` + `blur(24px)`，其下压一层 `rgba(8,10,18,.34)` 遮罩——**遮罩必须在弹层之下**，否则会出现透底、气泡半露等重叠伪影（旧稿 04/05 帧的问题）
- 文字：主 13/500 · 次要 11 `rgba(255,255,255,.60)`；圆角 18 / 12 / 9；语义色 accent `#0a84ff`、ok `#34c759`、danger `#ff6b6b`
- 顶栏：分段 **待办 | 对话** + 仅 **···**（置顶 / 隐藏 / 模型配置）；待办页内再分段 **待办 | 已完成**
- 托盘菜单在窗体外（菜单栏托盘图标下方）
- 设计稿用深 / 浅两张真实壁纸验证玻璃表现（壁纸是装饰素材、不属产品界面；Wikimedia Commons，CC BY-SA 4.0）
- 日期字段暂不做；对话页不展示当前模型名；空状态 / 首次启动只做「待办列表为空」

## 待办

- 底部单行回车添加；点标题 → 编辑 sheet（删除 / 取消 / 保存，标题必填）
- 一条 todo **可绑多个工具、多个会话**；列表右侧用 **竖条数字（样式 I）**，不铺会话胶囊
- 点竖条数字 → 会话列表 sheet → 打开某一会话 / **再绑一个 AI**（另一工具，完整重走选工具→cwd→启动）
- 完成只改 `status`；已完成项变淡 + 标题横线，可取消

## 绑 AI

- 创建成功后底部 sheet：选本机已检测到的工具（未安装不展示）→ cwd（文件夹按钮打开系统选目录）→ 启动 → **成功页 3 秒顺时针环自动关闭**（无「完成」按钮）
- 成功页要给出剪贴板提示（文案已复制，到会话里粘贴）
- 失败按实际报错；可跳过稍后再绑

## 对话

- 左上列表图标展开会话列表（含新建）；会话标题取首条消息前 16 字
- 模型配置从 `···` 或未配置引导卡进入（供应商 / 模型 / API Key / 测试连接）；模型配置为**整页视图**，只出现一个标题

## 数据合同变更

- `todo.ai` 从单对象改为 **绑定数组**（toolId / sessionId / cwd / 显示名 / 时间）
- IPC / 存储需支持多绑定；完成仍只改 status

## 与当前实现的差异（待对齐）

锁定稿是设计源，`apps/desktop` 现有 v0.3 面板尚未按稿实现，已知差异：

- 顶栏：代码是 `Tick Todo Panel` + `📌置顶` + `⌄菜单`，稿是「分段 待办|对话 + 仅 ···」
- 会话入口：代码用行内展开详情，稿用竖条数字 → 会话 sheet
- 已完成：代码是底部「已完成 N 项」链接，稿是页内分段
- 玻璃：代码窗口未开 `transparent` / `vibrancy`，也没有 `backdrop-filter`，目前是纯深色不透明主题
